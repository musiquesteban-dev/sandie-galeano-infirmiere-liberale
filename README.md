# Site — Sandie Galeano

Site vitrine responsive pour Sandie Galeano, infirmière libérale à Merville.

## Aperçu

Le site comprend :

- une page d’accueil avec un accès direct au téléphone ;
- les principales catégories de soins ;
- la zone d’intervention ;
- les informations de contact et une mention d’urgence.

Le projet ne nécessite aucune installation ni dépendance : tout est contenu dans `index.html`.

## Ouvrir le site

Double-cliquez simplement sur `index.html`, ou ouvrez-le dans un navigateur.

## Modifier les informations

Ouvrez `index.html` dans un éditeur de texte puis utilisez la recherche pour remplacer les informations à confirmer :

- numéro de téléphone : `06 84 97 75 01` ;
- adresse : `5 bis, rue Joseph Bon, 31330 Merville` ;
- horaires et disponibilités ;
- zone d’intervention ;
- liste des soins proposés.

Les liens téléphoniques utilisent aussi ce numéro sous la forme `tel:+33684977501` : pensez à le modifier également si nécessaire.

## Avant publication

1. Faire valider tous les contenus par Sandie, particulièrement les horaires, l’adresse et les soins pratiqués.
2. Ajouter les mentions légales, une politique de confidentialité et les coordonnées de l’hébergeur.
3. Choisir un nom de domaine et un hébergeur, puis y déposer le fichier `index.html`.
4. Vérifier le rendu sur téléphone et tester les boutons d’appel.
